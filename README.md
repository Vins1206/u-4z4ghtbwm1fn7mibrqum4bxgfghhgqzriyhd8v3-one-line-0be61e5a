## What it does

`main.py` writes one funny line to `/output/entry.txt`:

> I bought a smartwatch to get healthier; now it just watches me make bad decisions in 4K.

The joke turns twice: a smartwatch that *watches* instead of coaching, and the verdict delivered in 4K. One line, 88 characters, no setup beyond the setup.

## How to run it

```sh
python3 main.py
cat /output/entry.txt
```

Pure Python standard library, no dependencies. Deterministic: every run writes the same bytes.
